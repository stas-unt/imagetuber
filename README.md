# ImageTuber

Виртуальный аватар Vtuber'a, требующий ТОЛЬКО микрофон. Без ИИ и (виртуальных) камер.

## Установка

### Ручная установка

Для работы программы нужен [Python](https://www.python.org/downloads/) (тестировалось на версии 3.14)

1. Клонируй репозиторий:
```bash
git clone https://github.com/stas-untitled/imagetuber.git
cd imagetuber
```
2. Создай виртуальное окружение (рекомендуется):
```bash
python -m venv venv
# Для Linux
source venv/bin/activate
# Для Windows
vent\Scripts\activate
```
3. Установи зависимости:
```bash
pip install -r requirements.txt
```

4. Запуск программы:
```bash
python main.py
```

## Конфигурация

Настройки программы находятся в файле config.toml.

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `device` | Выбранное устройство записи | default |
| `sample_rate` | Частота передискредитации | 48000 |
| `block_size` | Размер блока буфера | 1024 |
| `silence_threshold` | Порог уровня шума | 0.05 |
| `hysteresis` | Чем меньше значение, тем "резче" закрывается рот | 0.7 |
| `package` | Выбранный пакет лиц | default |

Пакеты лиц находятся в папке avatars программы. Каждый пакет содержит avatar.toml.

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `name`* | Название пакета лиц | Уникальное! |
| `author` | Имя/псевдоним создателя пакета лиц | Уникальное! |
| `provides_emotions`** | Определает, есть ли дополнительные эмоции | false |
| `emotions` | Указывает названия доступных эмоций | список |

`*Если имя пакета не указано, то он не появится в списке

**В разработке
`

Остальные параметры указывают путь к изображениям.

## Добавление в OBS

Просто добавь окно программы в сцену и выключи захват курсора мыши.

## Известные проблемы

* __Окно непрозрачное (Linux):__ Попробуй снять галочку на "Использовать формат текстур без прозрачности (обходной путь для Mesa)" в свойствах источника захвата окна приложения в OBS.
* __Я молчу, но рот не закрывается:__ Поиграйся с параметрами "Порог тишины" и "Гистерезис"
